🚀 Power BI Sales Analysis Dashboard | End-to-End Project <br>
As a fresher in Data Analytics, I built a complete interactive Sales Analysis dashboard for a clothing company dataset.<br>
📊 Key Highlights:<br>
 • Total Sales: 1.10M <br>
 • Total Profit: 132.52K <br>
 • 5K+ Orders Analyzed <br>
 • 500+ Cities Covered <br>
🔎 What I Did: <br> 
 ✔ Data cleaning & transformation using Power Query <br>
 ✔ Data modeling & relationships <br> 
 ✔ Created DAX measures for KPIs <br> 
 ✔ Built interactive dashboards with slicers <br>
 ✔ Region-wise, Category-wise & Time Series Analysis <br>
This project helped me understand how raw data turns into business insights. <br>
